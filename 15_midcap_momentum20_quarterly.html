The last report's "Momentum-20" was already a custom variant of the real Nifty Midcap150 Momentum 50 index (top 20 instead of top 50). This report changes a second thing on top of that: rebalancing every 3 months instead of the real index's actual May/November schedule. There is no official quarterly version of this index to compare against — this is purely "what if we turned the dial on this one custom setup," not a test of any product that exists.

The same survivorship bias as every reconstruction in this series still applies — today's NIFTY Midcap 150 roster, used retroactively back to 2008.

WHAT THIS SHOWS — exactly what changed, and what stayed identical.

Same universe (today's NIFTY Midcap 150), same formula (6m/12m risk-adjusted momentum, z-scored, asymmetrically normalised), same top-20 selection, same equal-weighting. Only the rebalance calendar changed: ▲ last trading day of Feb/May/Aug/Nov — four times a year — instead of just May/November. 72 rebalances computed (18 years × 4), same 2008-11-28–2026-08-24 window as the last report. No transaction costs are modelled for either cadence, so the extra turnover from rebalancing twice as often is invisible here — a real cost this comparison doesn't charge for.

Was it worth turning the dial?

▲ framing

WHAT THIS SHOWS — the direct answer to "what if we rebalanced every 3 months," net of what this comparison can't see.

Quarterly rebalancing added +2.93 percentage points of CAGR (+39.6% vs. +36.7%) and trimmed the worst drawdown slightly, using 72 rebalances instead of 36 over the same span — twice the portfolio turnover. Since this reconstruction models zero transaction costs anywhere, that comparison is unfairly generous to the more frequent schedule: in reality, doubling the number of full-portfolio reshuffles would cost real commission and slippage on every trade, which this report doesn't charge for. On the actual numbers shown, the gain is small enough that realistic trading costs could plausibly erase it — this result should be read as "roughly a wash, tilted slightly toward quarterly," not as "quarterly clearly wins."

Limitations

▲ read before trusting any number above

WHAT THIS SHOWS — every simplification carried over from the last report, plus the new ones from this comparison.

  • No transaction costs modelled — the quarterly schedule's small edge is shown before any commission, slippage, or market-impact cost from the doubled turnover; a cost-loaded version could easily flip the comparison.
  • Not a real index, and now doubly so — neither the top-20 selection nor the quarterly calendar exist at NSE.
  • Survivorship bias — today's Midcap 150 roster, applied retroactively, unchanged from the last report's caveat.
  • Equal-weighted, not free-float-market-cap × score; no F&O-eligibility screen; Feb/Aug rebalance dates are an arbitrary evenly-spaced insertion between the real index's actual May/November anchors, not derived from any published rule.
  • Midcap ETF's comparison figures cover only 2019-02-04–2026-08-24 (its real trading history), not the full window used for the momentum reconstructions and NIFTY 50.
  • Prices are unadjusted; no dividends are modelled for any series shown.
  • Only two rebalancing frequencies were tested (semi-annual, quarterly) — this is not a sweep, and monthly or annual rebalancing could show a different pattern entirely.
  • The report was generated while today's date (24 August) itself falls inside one of the quarterly rebalance months — so the very last "rebalance" in the 72-count is really a mid-August snapshot using whatever data exists so far, not a genuinely completed month like every rebalance before it. This affects only that one final data point.
