Why this window looks so much better than report 24's

▲ framing

WHAT THIS SHOWS — the mechanism, not just the scoreboard.

2020-2023 contains one of the sharpest V-shaped recoveries in Indian market history: the March 2020 COVID crash, followed by a multi-year midcap bull run that rewarded exactly the kind of stock this strategy is built to catch — names already showing strong 6/12-month price strength kept extending those gains through 2021-2023. That regime is close to a best-case scenario for a momentum-chasing rule, which is why win rate here (72.5%) is so much higher than report 24's 47.5% over 2024-2026, a choppier, more mean-reverting stretch for midcaps.

Put the two reports side by side and the lesson is the same one from report 25's rebalance-offset study: any single multi-year slice of this strategy's history can look dramatically better or worse than its 18-year average, purely because of which macro regime that slice happened to land in — strong trending markets favor momentum, choppy/reversal-prone markets punish it. Report 16/17's full-history 40.6% CAGR sits between this window's 61.1% and report 24's 1.0%, which is exactly what averaging across many different regimes should produce.

Limitations

▲ read before trusting any number above

WHAT THIS SHOWS — every simplification behind this backtest.

  • Today's fixed NIFTY Midcap 150 constituent list is applied retroactively across the whole window (survivorship bias) — same disclosed approximation as reports 11-19/24.
  • Every rebalance is modeled as a full sell-and-rebuy of the ENTIRE portfolio at that date's closing prices, even for stocks that stay in the top 10 — zero transaction costs, slippage, or taxes are modeled on any of these trades.
  • The window's end date (2023-12-29) happens to coincide almost exactly with the strategy's own December rebalance date, so the final 10 positions show up with 0% return / 0 days held — see the note under the trade log above.
  • Equal weighting (not free-float market-cap x momentum score) and no F&O-eligibility screen, same as every other reconstruction in this project.
  • Prices are unadjusted; no dividends are modeled for either the strategy's stock holdings or the benchmark ETF.
  • This is a single, fixed 4-year historical path chosen specifically because it contains the COVID crash and recovery — a deliberately eventful window, not a randomly-picked one, so its strong result should not be read as "typical."
