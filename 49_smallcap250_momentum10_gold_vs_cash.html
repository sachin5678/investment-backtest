▲ framing

WHAT THIS SHOWS — the mechanism, not just the scoreboard.

Same logic as report 48: gold's low correlation to Indian equities during broad selloffs means it doesn't need to rise to help here, it just needs to avoid crashing alongside the smallcap stocks the filter is protecting against. Since the regime signal is unchanged (NIFTY 50's own 200-EMA), the cash-vs-gold comparison isolates purely what's HELD during risk-off periods, and that isolation produces the same result on this second, more volatile universe.

The same caveat from report 48 applies: gold and equities CAN fall together during a genuine liquidity crunch — this window now DOES include the 2008-2009 global financial crisis (gold's real data starts 2009-01-02, essentially the full window), so that risk is at least partially represented here, unlike the shorter window an earlier version of this report mistakenly used.

Limitations

▲ read before trusting any number above

WHAT THIS SHOWS — every simplification behind this backtest.

  • GOLDBEES.NS's real history starts 2009-01-02 — the first two calendar days of this window use a forward/backward-filled gold price rather than a real traded one, a negligible approximation over an 18-year span.
  • Zero transaction costs on ANY regime switch (into or out of gold) — same disclosed omission as reports 42-48.
  • GOLDBEES.NS tracks domestic gold prices in INR, which also move with the rupee's own exchange rate.
  • Only ONE EMA span (200 days) and immediate-switch (no confirmation delay) were tested here.
  • No official "Smallcap250 Momentum 10" index exists — the June/December cadence is a borrowed convention. Today's fixed constituent list is applied retroactively (survivorship bias). Equal weighting, no F&O-eligibility screen, unadjusted prices, no dividends modeled — same as every other reconstruction here.
