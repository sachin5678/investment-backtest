▲ framing

WHAT THIS SHOWS — the mechanism, not just the scoreboard.

Smallcap stocks are typically more volatile than midcaps, so a bigger dispersion in the inverse-vol weights across the top 10 might be expected here — yet the CAGR-vs-drawdown trade-off comes out about the same shape as report 51's. That's because the reweighting only ever operates WITHIN the already-selected top 10 at any given rebalance; it can't do anything about a market-wide selloff that drags every smallcap down together, which is what actually drives most of this strategy's biggest drawdowns (see report 44's 200-EMA filter for a change that DOES address that).

As in report 51, the picks are IDENTICAL between equal-weight and inverse-vol — this report isolates the weighting scheme alone, not a different selection.

Limitations

▲ read before trusting any number above

WHAT THIS SHOWS — every simplification behind this backtest.

  • Weights are recomputed fresh at EVERY rebalance from a 1-year trailing window — a short, unusual volatility spike right before a rebalance date could distort a stock's weight for the following 6 months.
  • No cap or floor on individual weights (see the sample weights table above for how uneven this can get).
  • Zero transaction costs, slippage, or taxes modeled — same as every other reconstruction in this project.
  • Only inverse-1-year-volatility weighting was tested — a different lookback or weighting rule could produce a different trade-off.
  • No official "Smallcap250 Momentum 10" index exists — the June/December cadence is a borrowed convention. Today's fixed constituent list is applied retroactively (survivorship bias). This is a single, fixed 18-year historical path.
