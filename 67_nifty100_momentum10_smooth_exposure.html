● the pattern reverses — the binary filter dominates EVERY smooth band

On NIFTY100, the binary filter (+30.7% CAGR / -25.6% drawdown) beats EVERY smooth band on BOTH dimensions — 10% (+29.7% / -25.7%), 15% (+30.1% / -25.9%), and 20% (+30.4% / -26.0%). This is the OPPOSITE of Smallcap250's result (report 66), where the wider smooth bands dominated the binary filter instead.

Lined up with reports 65-66, the honest pattern: the binary filter's whipsaw cost is only worth removing (via smoothing) when that whipsaw cost is large to begin with. NIFTY100's binary filter has 69 re-entries — the SAME regime-signal count as every other universe (since the signal is NIFTY 50's own price, independent of what it protects) — but a calmer, lower-volatility universe like NIFTY100 apparently pays a smaller whipsaw tax for the SAME number of round-trips than a choppier one like Smallcap250 does, leaving less for smoothing to recover.

Reading three universes together

▲ framing

WHAT THIS SHOWS — the mechanism, not just the scoreboard.

NIFTY100's own unfiltered drawdown (-35.3%) is the SHALLOWEST of the three universes tested across reports 65-67 — shallower than Midcap150's and much shallower than Smallcap250's. Report 45 already found the binary filter costs NIFTY100 almost nothing in CAGR (30.70% -> 30.67%) — there was very little whipsaw damage for smoothing to recover in the first place, so a smoother ramp here just gives up some of the binary filter's clean, sharp de-risking without much offsetting benefit.

Put the three reports together and a genuinely useful rule of thumb emerges: smooth exposure scaling is worth trying specifically on universes where the binary filter ALREADY shows meaningful whipsaw cost (like Smallcap250); on a universe where the binary filter is already nearly free (like NIFTY100), there's less to gain and the binary switch's crisper full de-risking wins outright. This is exactly the kind of conditional, universe-dependent finding this project has repeatedly surfaced (see also reports 37-41's front-loaded momentum) — no single design choice is universally best.

Limitations

▲ read before trusting any number above

WHAT THIS SHOWS — every simplification behind this backtest.

  • This is a SIMPLIFIED implementation: exposure scales the ALREADY-COMPUTED fully-invested strategy's own daily returns, not a re-simulation of actual partial share purchases.
  • Exposure uses YESTERDAY's close-to-EMA ratio to scale TODAY's return, avoiding same-day look-ahead.
  • Cash (the unexposed portion) earns exactly 0%, same convention as every cash-holding report here.
  • Only three band widths were tested (10%/15%/20%) — none of them beat the binary filter here, but a wider or narrower band wasn't checked and might close the gap.
  • Today's fixed NIFTY100 constituent list (report 12's config) is applied retroactively (survivorship bias). This is a single, fixed historical path.
