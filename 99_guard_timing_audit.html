Timing Audit — the Gold-Strength Guard's +11.5pp That Wasn't

Reports 91/92 introduced a guard on report 48's hedge leg: during a risk-off period, hold gold only while gold's own ~6-month return beats NIFTY's and is positive — else sit in flat cash. The first release claimed the guard added 11.5–11.9 points of CAGR on every rebalance calendar and cut drawdown to −20.0%. This report recomputes the published logic exactly as it shipped, side by side with the corrected logic, on one identical window, and accounts for every rupee of the difference.

● same code, two timings: +12.35pp of CAGR collapses to +0.30pp

The published guard showed CAGR rising from +42.0% to +54.4% — a terminal multiple of 4.43× report 48. Corrected, the same guard produces +42.3% — 1.04×. Roughly all of the difference came from two classes of days where the published code used information it could not have had live: flip-off days (whose realized return in report 48 is still stocks — the switch executes at that day's close) and same-day exit checks (flat cash applied to the very close that tripped the check).

What survives is honest and small: +42.3% vs +42.0% (+0.30pp), with max drawdown improving +1.67pp (-24.3% → -22.6%). Reports 91 and 92 now publish these corrected numbers; this report is the audit trail.

One more page carried the same phantom: the earlier findings-round release of this idea (the "Gold-Strength Guard Before Switching to Gold" finding, f10) published the identical double-digit gains across Midcap150, Smallcap250 and NIFTY100, on the same flawed day-level masks. It has been regenerated with this fix — its Midcap150 top-10 "both checks" variant now reads 42.08% CAGR / −22.63% drawdown (report 48's own, same window: 42.01% / −23.42%), versus the 54.80% / −19.95% it published at its older data vintage — and across all nine universe/size variants the honest effect runs −0.2 to +0.9pp of CAGR with drawdown between 0.8pp better and 1.4pp worse.

A second findings page, "Wild Combinations on Report 48" (f3), carried the same class of phantom: its two gold-trend-filter variants (G/H) were that batch's headline at 53.2% / 53.5% CAGR, having read gold's own trend with each day's close and substituted the same day's return on the very close that tripped the check. Corrected to the prior-close convention they land at 43.21% / −22.6% and 42.90% / −23.2% (report 48's own, same window: 42.01% / −23.42%) — real but small: +1.2pp and +0.9pp of CAGR with drawdowns 0.2–0.8pp shallower. The page and its results file have been regenerated.

Mechanism 2 — same-day exit checks (43 days)

▲ smaller, same disease

The arithmetic — every rupee accounted for

▲ reconciliation

The two mechanisms touch disjoint sets of days, so their effects multiply: 2.02× (zeroing same-day-detected fail days — the "small" half) × 2.19× (resubstituting boundary and transition days with gold) = 4.43× — exactly the published terminal multiple. With both corrected, the guard's multiple over report 48 is 1.04×. Over a 2009-01-02–2026-11-06 window, a 4.43× head start compounds to the +12.35pp of CAGR that was published; 1.04× compounds to +0.30pp.

Limitations & the general lesson

▲ read before trusting any number above
  • The corrected guard itself is not "proven good": +0.30pp of CAGR is inside any plausible cost band, and −1.67pp of drawdown is a trim, not a transformation. Reports 91/92 now present it that way.
  • The rule this audit enforces project-wide: strategies that act at a day's close must be evaluated on PRIOR-close information — a day's realized return belongs to the state decided at the previous close. Any day-level substitution (hedge swaps, exit checks, recovery dodges) is exactly where this class of bug hides, and aggregate metrics cannot see it — crash-day tables are the only way.
  • Zero transaction costs throughout, matching reports 91/92's own convention; the guard adds few extra switch events (~259 flat days across 21-odd regime blocks), so costs do not change the audit's conclusions about the artifact.
  • Same reconstruction caveats as everywhere in this project: today's fixed Midcap150 constituent list applied retroactively (survivorship bias), equal weighting, unadjusted prices, no dividends.
