# Investment Backtest — NIFTY / Midcap / Smallcap Strategy Lab

20 hand-rolled Python backtests of trading, SIP, and factor-index strategies
on Indian markets (NIFTY 50, NIFTY Midcap 150, NIFTY Smallcap 250, NIFTY
500), each with a self-contained HTML report and, together, a proper React
web app for browsing all of them day to day.

## What's in here

- **`backtest*.py`** — 20 backtest engines, hand-written event loops (no
  backtesting library), covering: a 20-day-high/10-day-low breakout system,
  cash/NIFTY dip timing, NIFTY→midcap ATH-drawdown rotation, several SIP +
  tactical-overlay combinations, real NSE momentum/quality factor-index
  reconstructions (NIFTY200 Momentum 30, Midcap150 Momentum, NIFTY500
  Momentum, NIFTY500 Quality 50), custom top-N variants, a sector-first
  momentum rotation, and a momentum+gold blend with a drawdown-triggered
  reallocation rule.
- **`build_html*.py`** → **`NN_*.html`** — one self-contained static HTML
  report per backtest (dark theme, inline SVG charts, no build step —
  open directly in a browser).
- **`dashboard.html`** — a sidebar-navigation hub that loads every report
  into one page via iframes (generated by `build_dashboard.py`).
- **`webapp/`** — a Vite + React + Tailwind app covering the same 20
  reports with native (Recharts) charts, generic schema-driven data loading,
  and a GitHub-Pages-ready build. See [`webapp/README.md`](webapp/README.md)
  for local dev and deployment instructions.
- **`svg_charts.py`**, **`*_symbols.py`**, **`fetch_*.py`**,
  **`extract_report_content.py`** — shared chart-rendering helpers, NSE
  constituent lists, yfinance data-fetch scripts, and the HTML→JSON prose
  extractor that feeds the webapp's "read the full analysis" sections.
- **`results*.json`** — the numeric output of each backtest (equity curves,
  CAGR, drawdown, etc.) — consumed by both the static HTML reports and the
  webapp.

Every report follows the same honesty rules: assumptions are called out
explicitly (amber pills), every non-empty "Limitations" panel is mandatory,
and no result is dressed up — several reports here report a strategy
*underperforming* a simpler alternative, on purpose.

## Quick start

**View a report:** open any `NN_*.html` file directly in a browser, or open
`dashboard.html` for the full sidebar-navigable hub — both are plain static
files, no server needed.

**Run the web app locally:**
```bash
cd webapp
npm install
npm run dev
```

**Re-run a backtest** (requires the raw price caches — see below):
```bash
py -3 backtest19.py   # writes results18.json
py -3 build_html19.py # writes 19_sector_momentum_rotation.html
```

## Data caches (not committed)

`*.pkl` files (raw yfinance OHLC price history for ~500+ NSE tickers,
~200MB total) are gitignored — they're large and fully regenerable, and
nothing here needs them except re-running a backtest from scratch. To
rebuild them, run the relevant `fetch_*.py` script (see each backtest's
docstring for which cache it expects).

## Deploying the webapp

See [`webapp/README.md`](webapp/README.md) — it's already configured for
GitHub Pages (`HashRouter`, relative `base: './'`) with a ready-to-use
GitHub Actions workflow.
